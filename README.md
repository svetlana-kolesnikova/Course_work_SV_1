# Приложение для анализа транзакций
Приложение генерирует JSON-данные для веб-страниц

### Инструкция по установке:
1. Создать форк репозитория [GitHub](https://github.com/svetlana-kolesnikova/Last_operayion_9.1)

2. Убрать галочку с "Copy the main brunch only"

3. Скопировать код по ssh-ключу, либо по токену.

4. В локальном EDI вставить ключ

5. Установите необходимые инструменты для работы из 
файла "[pyproject.toml](../PythonProject/Last_operations_9.1/pyproject.toml)"

6. В файле [.env.sample](.env.sample) замените "your_api_key_here"
на API-ключ, полученный на сайте [ALPHA VANTAGE](https://www.alphavantage.co) 

### Работа программы.
- Запустите программу в файле [main.py](main.py).

- Следуйте последовательным указаниям программы.


### Описание вспомогательных модулей:
1. Модуль [excel_reader.py](src/excel_reader.py).
Читает файл в формате Excel из папки [data](data)

2. Модуль [reports.py](src/reports.py).
Выводит средние траты в рабочий и в выходной день за последние три месяца (от переданной даты).
Если дата не передана, то берется текущая дата.

3. Модуль [save_to_json_file.py](src/save_to_json_file.py).
Производит охранение файла по указанному пути.

4. Модуль [services.py](src/services.py).
Выводит транзакции с телефонными номерами.

5. Модуль [utils.py](src/utils.py).
Содержит вспомогательные функции для модуля [views.py](src/views.py)

6. Модуль [views.py](src/views.py).
Выводит данные в формате JSON для страницы "Главная".

### Запуск тестирования. 
Для запуска тестов через терминал необходимо ввести команду *pytest*. Либо правой кнопкой мыши нужно нажать 
на пакет "tests" и выбрать из списка "Run 'Python tests in test...'"
